# log — 历史记录

> **append-only**：只新增，不修改已写内容。记录「已完成的一次性工作」，不是活契约。
> 活契约（编码规范、响应契约、权限设计…）留在 `docs/` 上一层，**不要搬进来**。
> 进行中的事不放这里 → 放 `docs/CONTEXT.md`。

## 命名

```
YYYYMMDD_主题.md
```

- 日期前缀保证排序，主题用中文短词。
- 头部固定字段：**日期 / 状态 / 关联 tag / 一句话结论**。

## 何时写一条

- 一个 milestone / 一批改造完成，且 `CONTEXT.md` 里要清出去时。
- 做过的**决策**（选了 A 不选 B，为什么）——这是最值得留的。
- 踩了新的坑 → 追加到 `docs/坑与约束.md`，不必单开 log。
