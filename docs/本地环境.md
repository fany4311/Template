# 本地环境

## 依赖容器

Docker 环境（MySQL / Redis / MinIO）在 `~/Docker`，每服务一个 `compose.yaml` + `./data` 挂载。

| 容器 | 端口 | 说明 |
|---|---|---|
| `mysql` | 3306 | 库 `template`（dev）/ `template_tmp`（e2e，tmp 类） |
| `redis` | 6379 | dev 用 DB 1，e2e 用 DB 2 |
| `minio` | 9010 / 9011 | API / 控制台；bucket `template`（私有） |

## 数据库

**库名 / 账号 / 授权的唯一定义在 `server/sql/databases.sql`**，角色与理由在 `docs/库台账.md`。
本文件只说本地怎么跑。

| 库 | 角色 | 账号 | 用途 | 初始化 |
|---|---|---|---|---|
| `template` | dev | `template_dev` | 开发（`NODE_ENV=dev`） | `pnpm migration:run` |
| `template_tmp` | tmp | `template_tmp` | e2e / 生成器验证 / 恢复演练 | `bash scripts/db-reset.sh` |

**一库一账号**：`template_dev` 只被授了 `template.*`，读写不了 `template_tmp` 与 `template_prod`。
三份密码互不相同，存在各自的 `.env` 里。

**两库物理隔离**：e2e 写入不污染开发数据，dev server 开着也能直接跑 e2e
（否则 dev 的 Outbox 轮询器会抢走 e2e 插入的事件）。

```bash
# 从零重建测试库（DROP → CREATE utf8mb4_unicode_ci → 授权 → 迁移，一条命令）
bash scripts/db-reset.sh
# 建库建号：bash scripts/db-apply.sh（读三份 .env 的密码渲染后执行，一次即可）

cd trunk/server
NODE_ENV=test pnpm migration:run     # 测试库
pnpm migration:run                    # 开发库
```

## 迁移的约定

- **已执行过的迁移不可修改**，修正一律追加新迁移。
- `1766999990000-CreateCoreSchema` 是**基线建表迁移**，必须先于所有 seed 执行
  （核心表原本靠 `DB_SYNCHRONIZE=true` 自动建，空库跑迁移会失败）。
- 生产 `DB_SYNCHRONIZE` **必须 `false`**。

## 常用命令

```bash
cd trunk/server
pnpm start:dev      # 开发（NODE_ENV=dev，端口 3010；3000 留给 prod）
pnpm test           # 单测
pnpm test:e2e       # e2e（独立库，串行）
pnpm lint           # oxlint --type-aware
pnpm openapi:dump   # 导出 openapi.json 供前端 codegen

cd trunk/web_admin
pnpm dev            # 5183，代理 /api → 3010
pnpm openapi:gen    # openapi.json → src/api/schema.d.ts
pnpm build          # 产物由 Nginx 托管（8080）

cd trunk/web
pnpm dev            # 5184，代理 /api → 3010
pnpm build          # 产物由 Nginx 托管（8084）
```

或走 PM2 一把起三件套（与生产一致）：

```bash
bash deploy/template.sh dev start|status|stop
```

## 端口一览（dev / prod 可同时跑）

| | dev | prod |
|---|---|---|
| 后端 | **3010**（`.env.dev`） | **3000**（`.env.prod`） |
| 后台 web_admin | 5183（vite） | 8080（Nginx） |
| 前端 web | 5184（vite） | 8084（Nginx） |

vite 都开 `strictPort`：端口被占**直接报错**，不悄悄换端口（换了的结果是「你改的代码没生效」，更难查）。

## E2E（Playwright）

```bash
cd web_admin
npx playwright install chromium      # 首次；需要能访问 playwright CDN
pnpm test:e2e                        # 要求 dev 三进程已在跑（5183）
```

- 用例只覆盖金链路；配置 `workers: 1`（共用后端与库，并行会互相踩数据）。
- 演示账号 `manager_bw / Demo@12345`（迁移 seed，生产库不生成）。
- 需要超管的用例用 `E2E_ADMIN_USER` / `E2E_ADMIN_PASS` 覆盖，未配置自动 skip。
- **WSL2 没有 IPv6 出口，而 `cdn.playwright.dev` 只解析到 AAAA**，Node 默认优先 IPv6 →
  下载卡住不报错。强制 IPv4 即可：

  ```bash
  NODE_OPTIONS=--dns-result-order=ipv4first npx playwright install chromium
  ```

  验证：`curl -4 -sI https://cdn.playwright.dev/` 有响应（400/200 都算通），`curl -6` 是 000。
