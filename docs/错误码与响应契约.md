# 响应与错误码契约

> 前端与后端、校内与省平台适配层之间，边界承诺**稳定、可演进、可审计**。
> 兼顾若依风格（HTTP 200 + `body.code`）与 Nest 12 内置 `errorCode`。

## 1. 成功响应

`TransformInterceptor` 统一包装：

```json
{ "code": 200, "msg": "操作成功", "data": { } }
```

- 跳过包装：`@Keep()`（文件下载、健康检查等非标准结构）。
- 响应头附 `X-Trace-Id`（CLS 生成）。

## 2. 错误响应

`AllExceptionFilter` 统一输出：

```json
{ "code": 500, "msg": "用户名或密码错误", "data": null, "traceId": "…" }
```

| 场景 | HTTP | body.code |
|---|---|---|
| 业务异常 `ApiException` | **200** | 业务码（默认 500），**保留 `code` 兼容旧前端** |
| 未登录/过期 | 401 | 401 |
| 无权限 | 403 | 403 |
| 参数校验失败（Standard Schema） | 400 | 400，`msg` 为逐字段问题 |
| 其它框架异常 | 原始状态码 | statusCode |
| 未知/DB 异常 | 500 | 500（不泄露 SQL） |

## 3. 机器可读错误码（errorCode）

Nest 12 的 `HttpExceptionOptions.errorCode` 会序列化进响应体，供客户端稳定分支：

```ts
throw new BadRequestException('密码强度不足', { errorCode: 'WEAK_PASSWORD' });
```

约定：**大写下划线**字符串、全局唯一。命名分组（规划）：

| 前缀 | 域 |
|---|---|
| `AUTH_*` | 认证（`AUTH_TOKEN_EXPIRED`、`AUTH_ACCOUNT_DISABLED`） |
| `PERM_*` | 权限（`PERM_DENIED`、`PERM_DATA_SCOPE`） |
| `VALID_*` | 校验 |
| `USER_*` / `ROLE_*` | 用户 / 角色 |
| `SYNC_*` | 省平台同步（`SYNC_UPSTREAM_FAIL`…） |
| `SYS_*` | 系统（`SYS_DB_ERROR`、`SYS_INTERNAL`） |

## 4. 校验错误形态

`StandardSchemaValidationPipe` 默认 400，`msg` 形如
`username: Invalid input: expected string, received undefined; ...`，
`data` 同时携带原始问题数组，便于前端逐字段标红。

## 5. 演进原则

1. **只增不改**：已发布的 `code` / `errorCode` 语义不随意变更。
2. **版本化**：破坏性变更走 `/api/v2`；旧版可加 `Deprecation` / `Sunset` 响应头。
3. **可审计**：上报/同步类接口须能通过 `traceId` 关联审计日志。
4. **省平台适配**：对外响应结构由 adapter 层单独映射，不污染校内契约。

## 6. 响应 schema 声明（强制）

每个接口都必须用 `@ApiOkZod(组件名, dataSchema, 说明)` 声明成功响应，
它是**前后端类型自动化的唯一来源**（`src/common/swagger/api-ok.ts`）。

```ts
@Get()
@ApiOkZod('SysUserPage', pageOf(userResponseSchema), '分页结果 { list, total }')
page(@Query({ schema: queryUserSchema }) query: QueryUserInput) { ... }
```

约定：

1. **只描述 `data`**：`{ code, msg, data }` 包络由工具补，不要手写。
2. **组件名即契约名**，全局唯一且同名必须同结构（加载期校验，重名不同结构直接启动失败）。
3. **无返回体**用 `null`，返回布尔用 `z.boolean()`。
4. **递归树**（部门/菜单）用 `z.lazy`；工具会把递归体抽成 `<组件名>Data` 并自动修正 `$ref`。
5. **响应 schema 放 `dto/*.response.ts`**，与入参 `dto/*.dto.ts` 分开（入参宽松、出参严格）。
6. **同一份 schema 必须能被真实响应解析** —— `test/contract.e2e-spec.ts` 用它校验返回，漂移会让 e2e 直接失败。

方言：转换走 Zod 的 Standard JSON Schema（`target: 'openapi-3.0'`），与 Nest 12 转换请求体同源，产出 3.0 语义（`nullable` / `exclusiveMinimum: true`），不混入 3.1 写法。
